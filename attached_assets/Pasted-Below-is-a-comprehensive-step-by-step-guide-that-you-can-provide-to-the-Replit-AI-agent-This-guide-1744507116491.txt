## 2. Supabase Integration and Data Model Migration

**2.1 Create a Supabase Client Module**  
The agent should generate a module (for example, `supabase_client.py` in Python) with the following responsibilities:
- Initialize the Supabase client using environment variables.
- Provide functions for common CRUD operations.  
_Sample Code (Python):_
```python
import os
from supabase import create_client, Client

SUPABASE_URL = os.getenv("SUPABASE_URL")
SUPABASE_ANON_KEY = os.getenv("SUPABASE_ANON_KEY")

if not SUPABASE_URL or not SUPABASE_ANON_KEY:
    raise EnvironmentError("Missing Supabase credentials.")

supabase: Client = create_client(SUPABASE_URL, SUPABASE_ANON_KEY)

def fetch_properties():
    response = supabase.table("properties").select("*").execute()
    if response.error:
        raise Exception("Error fetching properties: " + str(response.error))
    return response.data

def insert_property(property_record):
    response = supabase.table("properties").insert(property_record).execute()
    if response.error:
        raise Exception("Error inserting property: " + str(response.error))
    return response.data
```
- **Data Model Migration:**  
  - The AI agent should generate migration scripts to map the current PostgreSQL schema for properties, assessments, accounts, etc., into Supabase tables.
  - Use Supabase’s dashboard SQL editor if necessary to create or modify table schemas.

**2.2 Testing Database Operations**  
- Have the agent run tests to validate that the Supabase client module can fetch, insert, update, and delete data.
- Automated tests should be created to ensure proper migration and data integrity.

## 3. JWT Authentication Integration

**3.1 JWT Module Implementation**  
- **Implement Authentication Endpoints:**  
  Create endpoints for user login and signup. On successful authentication, generate a JWT token using the secret key (JWT_SECRET).  
_Sample Pseudocode (Python):_
```python
import jwt
import datetime

def generate_jwt(user_info):
    token = jwt.encode(
        {
            "user_id": user_info["id"],
            "exp": datetime.datetime.utcnow() + datetime.timedelta(hours=1)
        },
        os.getenv("JWT_SECRET"),
        algorithm="HS256"
    )
    return token

def verify_jwt(token):
    try:
        decoded = jwt.decode(token, os.getenv("JWT_SECRET"), algorithms=["HS256"])
        return decoded
    except jwt.ExpiredSignatureError:
        raise Exception("Token expired")
    except jwt.InvalidTokenError:
        raise Exception("Invalid token")
```

**3.2 Integrate JWT with Supabase Security**  
- Enforce role-based access at both the API layer (using JWT verification) and at the database level by configuring Supabase’s row-level security policies.
- The AI agent should automate the creation of these policies based on defined user roles.
